# Chapter 02 – Classes and Objects

This chapter explores the fundamental building blocks of Object-Oriented Programming in C++: **Classes and Objects**. It focuses on data encapsulation, access control, constructors, destructors, and various member functions.

## 📚 Topics Covered

- Introduction to Classes and Objects
- Scope Resolution Operator (`::`)
- Data Members and Member Functions
- Encapsulation and Data Hiding
- Visibility / Access Specifiers:
  - Public
  - Private
  - Protected
- Constructors:
  - Default Constructor
  - Parameterized Constructor
  - Copy Constructor
- Destructors
- Static Data Members
- Static Member Functions
- Inline Functions
- Friend Class
- Friend Functions
- Passing Objects as Function Arguments

## 🎯 Learning Outcomes

- Understand class and object creation in C++.
- Implement encapsulation and data hiding.
- Understand different types of constructors and destructors.
- Work with static members and inline functions.
- Understand the purpose of friend classes and friend functions.
- Learn how to pass objects to functions.

## 💻 Language Used

**C++**
