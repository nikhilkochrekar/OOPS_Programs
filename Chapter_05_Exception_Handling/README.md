# Chapter 05 – Exception Handling

This chapter focuses on **Exception Handling** in C++, a mechanism used to detect and manage runtime errors without abruptly terminating program execution. It explores the use of `try`, `throw`, and `catch` blocks to handle exceptional situations effectively.

## 📚 Topics Covered

- Introduction to Exception Handling
- Throwing an Exception (`throw`)
- Try Block (`try`)
- Exception Handler (`catch`)
- Handling Multiple Exceptions
- Catch-All Block (`catch(...)`)
- Nested Try Blocks
- Exceptions with Arguments

## 🎯 Learning Outcomes

- Understand the importance of exception handling in C++.
- Identify and handle runtime errors.
- Implement `try`, `throw`, and `catch` mechanisms.
- Handle multiple types of exceptions.
- Understand catch-all handlers and nested try blocks.
- Pass and handle exception information using arguments.
- Write more robust and reliable C++ programs.

## 💻 Language Used

**C++**
