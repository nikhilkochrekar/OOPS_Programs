# Chapter 04 – Polymorphism

This chapter explores **Polymorphism**, one of the core principles of Object-Oriented Programming in C++. It demonstrates how a single interface can represent different forms of behavior through compile-time and runtime polymorphism.

## 📚 Topics Covered

- Introduction to Polymorphism
- Virtual Functions
- Pure Virtual Functions
- Abstract Classes
- Static Functions
- `this` Pointer
- Operator Overloading:
  - Unary Operator Overloading
  - Binary Operator Overloading
- Complex Number Operations:
  - Addition of Complex Numbers
  - Subtraction of Complex Numbers

## 🎯 Learning Outcomes

- Understand the concept and importance of polymorphism.
- Differentiate between compile-time and runtime polymorphism.
- Implement virtual and pure virtual functions.
- Understand abstract classes and their applications.
- Explore the use of the `this` pointer.
- Overload unary and binary operators in C++.
- Implement arithmetic operations on complex numbers using operator overloading.

## 💻 Language Used

**C++**
