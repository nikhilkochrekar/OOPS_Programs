## 📚 Course Contents

### Chapter 01 – Fundamental Concepts of Object-Oriented Programming

Introduction to programming fundamentals and basic problem-solving using C++.

**Topics Covered:**
- Introduction to Object-Oriented Programming
- Programming Fundamentals
- Arrays and Strings
- Functions and Methods
- Palindrome Program
- Finding the Largest Element in an Array
- Parameter Passing Techniques:
  - Pass by Value
  - Pass by Reference
  - Pass by Pointer

### Chapter 02 – Classes and Objects

Understanding the building blocks of Object-Oriented Programming through classes, objects, and their associated concepts.

**Topics Covered:**
- Introduction to Classes and Objects
- Scope Resolution Operator (`::`)
- Data Members and Member Functions
- Encapsulation and Data Hiding
- Access Specifiers:
  - Public
  - Private
  - Protected
- Constructors:
  - Default Constructor
  - Parameterized Constructor
  - Copy Constructor
- Destructors
- Static Data Members and Member Functions
- Inline Functions
- Friend Class and Friend Functions
- Passing Objects as Function Arguments

### Chapter 03 – Inheritance

Exploring code reusability and hierarchical relationships between classes using inheritance.

**Topics Covered:**
- Introduction to Inheritance
- Types of Inheritance:
  - Single Inheritance
  - Multilevel Inheritance
  - Multiple Inheritance
- Defining Derived Classes
- Base Class and Derived Class
- Access Specifiers in Inheritance
- Function Overriding
- Function Overloading
- Diamond Problem
- Virtual Base Classes
- Inheriting and Accessing Private Members

### Chapter 04 – Polymorphism

Understanding how C++ supports multiple forms of behavior through compile-time and runtime polymorphism.

**Topics Covered:**
- Virtual Functions
- Pure Virtual Functions
- Abstract Classes
- Static Functions
- `this` Pointer
- Operator Overloading:
  - Unary Operator Overloading
  - Binary Operator Overloading
- Complex Number Operations:
  - Addition
  - Subtraction

### Chapter 05 – Exception Handling

Learning how to identify, handle, and manage runtime errors using C++ exception-handling mechanisms.

**Topics Covered:**
- Introduction to Exception Handling
- Throwing Exceptions (`throw`)
- Try Blocks (`try`)
- Exception Handlers (`catch`)
- Handling Multiple Exceptions
- Catch-All Block
- Nested Try Blocks
- Exceptions with Arguments

Through these practical implementations, this repository aims to:

- Apply inheritance and polymorphism in real-world programming scenarios.
- Implement operator overloading and exception handling.
- Improve logical thinking and problem-solving abilities.
