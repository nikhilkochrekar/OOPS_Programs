# Chapter 03 – Inheritance

This chapter explores **Inheritance**, one of the fundamental principles of Object-Oriented Programming in C++. It focuses on code reusability, hierarchical relationships between classes, and extending existing classes through derived classes.

## 📚 Topics Covered

- Introduction to Inheritance
- Types of Inheritance:
  - Single Inheritance
  - Multilevel Inheritance
  - Multiple Inheritance
- Defining Derived Classes
- Base Class and Derived Class
- Access Specifiers in Inheritance:
  - Public
  - Private
  - Protected
- Function Overriding
- Function Overloading
- Diamond Problem
- Virtual Base Classes
- Accessing Private Members through Inheritance

## 🎯 Learning Outcomes

- Understand the concept and importance of inheritance.
- Implement different types of inheritance in C++.
- Understand the relationship between base and derived classes.
- Apply access specifiers in inheritance.
- Differentiate between function overloading and function overriding.
- Understand and resolve the Diamond Problem using virtual base classes.
- Improve code reusability through inheritance.

## 💻 Language Used

**C++**
