# Chapter 01 – Fundamental Concepts of Object-Oriented Programming

This chapter covers the fundamental concepts of programming using C++, focusing on building a strong foundation in programming logic, problem-solving, and basic programming constructs.

## 📚 Topics Covered

- **Introduction to OOP:** Overview of Object-Oriented Programming concepts and principles.
- **Programming Basics:** Basic C++ syntax, variables, data types, and operators.
- **Arrays:** Array declaration, initialization, traversal, and basic operations.
- **Strings:** String manipulation and common string operations.
- **Functions and Methods:** Function declaration, definition, calling, and parameter passing.
- **Palindrome Program:** Checking whether a given number or string is a palindrome.
- **Largest Element in an Array:** Finding the maximum element in an array.
- **Parameter Passing Techniques:**
  - Pass by Value
  - Pass by Reference
  - Pass by Pointer

## 🎯 Learning Outcomes

- Understand the fundamentals of C++ programming.
- Develop logical thinking through basic programming problems.
- Perform operations on arrays and strings.
- Understand functions and their usage.
- Differentiate between various parameter passing techniques.

## 💻 Language Used

**C++**
